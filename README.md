# Calisto Burger & BBQ

Prototipo funcional de landing, carta y pedidos por WhatsApp para Calisto Burger & BBQ.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run preview
```

La aplicación usa rutas de cliente. `vercel.json` incluye la reescritura necesaria para abrir directamente `/menu`, `/delivery` y las demás páginas.

## Aviso

Este repositorio es un prototipo no oficial. Antes de indexarlo o usarlo como sitio definitivo deben aprobarse textos legales, precios, fotografías y uso de marca. Mientras tanto, el proyecto incluye `noindex` y bloquea rastreadores en `robots.txt`.
